# 免费像素素材来源清单

开发期先用免费素材占位，避免自制美术卡进度。以下来源均可免费获取（注意各站许可证差异）。

## 推荐来源

| 来源 | 地址 | 说明 |
|------|------|------|
| **Kenney** | `https://kenney.nl` | CC0 协议（最宽松，可商用免署名），有 tileset、角色、UI 全套像素包，强烈推荐 |
| **itch.io** | `https://itch.io/game-assets/free` | 海量免费/低价像素素材，搜索 `pixel farm`、`stardew`、`tileset`、`crops` |
| **OpenGameArt** | `https://opengameart.org` | CC 开源素材库，像素 tileset、角色、音效丰富 |
| **CraftPix.net** | `https://craftpix.net/freebies` | 免费 2D 游戏素材，有农场、农作物、像素角色包 |
| **Unity/团结 Asset Store** | 编辑器内置 `Asset Store` | 免费 2D 像素包可直接导入项目 |
| **Lospec** | `https://lospec.com` | 像素画教程 + 调色板（将来自己做像素素材时用） |

## 针对本项目的搜索关键词

- 地图：`pixel farm tileset`、`top-down tileset`、`grass dirt tileset`
- 作物：`pixel crops`、`pixel vegetables`、`plant growth sprites`
- 角色：`pixel character spritesheet`、`farmer sprite`
- UI：`pixel ui`、`pixel inventory icons`

## 使用注意

1. **许可证**：`CC0` 最宽松（随便用）；`CC BY` 需署名作者；付费/商用前先看清条款。学习项目优先选 CC0 或"免费可商用"。
2. **像素设置**：导入后把 Sprite 的 `Pixels Per Unit` 统一（建议 16 或 32），`Filter Mode` 设为 `Point`，否则像素会模糊。
3. **先占位后替换**：原型阶段用素材商店的占位图跑通玩法，美术统一风格留到后期。
