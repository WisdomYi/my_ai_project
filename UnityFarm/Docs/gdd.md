# 星露谷风格农场游戏 · 游戏设计文档（GDD）

> 首版范围：核心种植循环（MVP）。技术栈：团结引擎（Unity 2022.3 LTS）+ C#。

## 1. 一句话概述

2D 像素风农场模拟游戏：玩家经营一块农场，耕地、播种、浇水、收获作物，在昼夜循环中体验种植与积累的乐趣。

## 2. 核心循环

```
耕地 → 播种 → 浇水 → 生长(时间流逝) → 收获 → 卖出 → 买种子 →（回到耕地）
```

- **耕地**：用锄头把草地变成可种植的耕地
- **播种**：在耕地上使用种子（消耗背包里的种子）
- **浇水**：对已播种的地浇水（当天浇过水才会生长）
- **生长**：作物按"天"推进生长阶段（幼苗 → 成长 → 成熟）
- **收获**：成熟作物收获进背包
- **卖出/买种子**：作物换金币，金币买新种子

## 3. 时间与节奏

- 游戏内一天 ≈ 现实 5~10 分钟
- 一天分时段：清晨 → 白天 → 黄昏 → 夜晚，夜晚可上床睡觉（结束当天）
- 作物以"天"为单位生长，**不是按秒**；睡觉时结算生长与存档

## 4. MVP 功能清单（第一版必须实现）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 农场地图 + 角色移动 | Tilemap 铺地图，WASD 移动角色 |
| 2 | 工具交互 | 锄地、浇水，对地块操作 |
| 3 | 作物系统 | `CropData`(ScriptableObject) 定义作物、生长阶段、成熟判定 |
| 4 | 背包/物品栏 UI | 显示种子与收获物 |
| 5 | 时间系统 | 游戏内时钟、天数、睡觉结算 |
| 6 | 存档系统 | JSON 序列化，保存/读取地块、作物、背包、时间 |

## 5. 不做清单（明确排除，防止范围蔓延）

- ❌ 商店 UI 动画、复杂经济平衡
- ❌ 季节系统、天气变化
- ❌ 钓鱼、采矿、战斗、畜牧
- ❌ 音效、音乐、角色动画（首版用静态图）
- ❌ 节日、事件、成就、任务系统
- ❌ 多人联机

## 6. 技术架构（对应 Assets/Scripts 目录）

- `Core/`：`GameManager`（入口）、`TimeManager`（时间）、`SaveSystem`（存档）
- `Gameplay/`：`Player`（移动）、`PlantingTool`（锄地/浇水）、`Crop`（地块作物状态）、`CropData`（作物数据定义）
- `UI/`：`InventoryUI`（背包）、`HUD`（界面）、`TimeUI`（时间显示）
- `Data/`：`CropData` 等 ScriptableObject 资产实例
